A · Scope & pipeline

范围与生成链路

公式以当前源码为准

每个样本由一个真实 dataset \(d\) 及其 profile \(b\)、一个能力 \(c\)、一个强度级别 \(k\in\{1,\dots,5\}\) 和一个随机种子 \(\xi\) 唯一确定。真实数据不提供待复制的 单条曲线，而提供 dataset-local nuisance、主特征容忍区间与两个回验门限。

01 · PROFILE提取真实统计分布季节长度、噪声、持续性、趋势背景、尾部与协变量残差。
02 · DOSE反标定能力剂量求 \(\lambda_{b,c}(k)\)，五档落在真实容忍与生成器响应的交集内。
03 · GENERATE执行机制生成器固定可预测结构，随机化相位、符号、负载与噪声。
04 · ACCEPT在线三重验收construction gate、feature-support gate、near-distance gate。
05 · AUDIT离线构念验收能力感知基线须稳定优于能力盲基线，并排除固定 seasonal-naive shortcut。

生成方程不是 intensity 定义

方程中的 \(A_c(k;b)\) 是结构参数；最终 intensity 由独立 seed bank 上主统计特征 \(f_c\) 的期望是否对齐该 dataset/profile 的可行目标 \(T_{b,c,k}\) 来定义，而不是逐样本筛选。

intensity 不是模型难度

它表示指定结构的可观测强度。结构更强可能更易识别，也可能更考验外推；模型误差是否单调是实验问题，不写入生成定义。

统计窗口。 本页附录中的 realized feature 在完整评测窗口 \(t=0,\ldots,C+H-1\) 上离线计算，用于 seed-bank 标定和事后诊断，不按某条 future 的主特征值拒绝样本；在线 feature-support gate 只约束预注册的 nuisance control。模型推理时仍只可看到 \(0,\ldots,C-1\) 以及协议允许的 known-future covariates。
为什么 capability contrast 不逐样本拒绝。 能力感知 construction oracle 可读取冻结的机制参数和协议允许的未来协变量， 能力盲基线只从历史选择通用预测器；二者都不读取未来目标，但误差比较必须在未来上评分。 若按单样本结果拒绝生成，会筛掉“对 oracle 不走运”的未来并产生选择偏差。 因此 contrast 只按预先固定的 seed bank 做聚合资格审计；在线元数据记录诊断， 但不参与某条样本是否被接收。聚合增益定义为 \(\overline{L_{\rm blind}-L_{\rm aware}}/\overline{L_{\rm blind}}\)， 并对配对 loss difference 计算单侧置信下界；不对每条样本的相对误差比例取平均， 以免 blind loss 接近零的简单样本获得畸高权重。发布资格在 I5 判定；其余档位 仍报告诊断，但 I1 可以是明确的 null 边界，不强求正 headroom。

B · Dataset-local intensity scale

Intensity 的逐数据集定义

q05 ≤ target ≤ 1.2×q95

对每个 dataset/profile 与能力，先从隔离的 parameter split 计算主特征真实容忍 区间 \([q05,1.2q95]\)，再与生成器的可达响应区间取交集，并反求交集内五档剂量 \(\lambda_{b,c}(k)\)。Intensity 编号只表示该 dataset 内从相对弱到相对强； 不同 dataset 的 I3 不要求具有相同主特征数值。

I-1 \[ I^{real}_{b,c} = \left[ Q_{.05}\!\left(f_c(R^{\mathrm{parameter}}_b)\right), 1.2Q_{.95}\!\left(f_c(R^{\mathrm{parameter}}_b)\right) \right]. \]

\(R^{\mathrm{parameter}}_b\) 只包含该 dataset 的无泄漏 parameter split；1.2 允许合成压力测试有限地高于真实典型高位。

I-2 \[ I^{feasible}_{b,c}=I^{real}_{b,c}\cap I^{gen}_{b,c}, \qquad T_{b,c,k}=\min I^{feasible}_{b,c} + r_k\left|I^{feasible}_{b,c}\right|, \quad r=(0,.25,.50,.75,1). \]

\(I^{gen}_{b,c}\) 是固定 profile nuisance 后，生成器在 \(\lambda\in[0,1]\) 上的主特征响应区间；不在交集之外外推。

I-3 \[ \lambda_{b,c}(k) = \arg\min_{\lambda\in[0,1]} \left| \mathbb{E}_{\xi} \!\left[f_c\!\left(G_c(b,\lambda;\xi)\right)\right] - T_{b,c,k} \right|, \qquad k\in\{1,\ldots,5\}. \]

\(G_c\) 为能力生成器，\(f_c\) 为主强度统计量；期望通过独立 seed bank 估计，并要求五档 realized mean 单调。

I-4 \[ A_c(k;b)=\kappa_{b,c}\bigl(\alpha_c+\beta_c\lambda_{b,c}(k)\bigr), \qquad \mathbb{E}_{\xi}[f_c(G_c)]\approx T_{b,c,k}. \]

大多数生成器采用上式的仿射剂量；非线性持续性还对依赖强度执行 \([0,1]\) 截断。Intensity 只缩放各节明确标出的机制强度；周期、相位、符号、载荷、事件时钟、递推族与 nuisance 在同 seed 的五档间保持不变。

五档在每个 supported dataset/profile 的可行交集内采用相同相对位置；target 数值由真实容忍与生成器响应共同决定。

多季节性 multi_seasonal

单目标三周期叠加主特征 multi_period_score
I↑：附加周期能量↑

保持 profile 主周期分量不变，从每个样本自己的有界候选池中选择两个可分辨附加周期，并逐档增强其能量，检验模型能否同时解析并延续多尺度周期结构。

生成方程

02-1 \[ \begin{aligned} P_{\max}&=\max(4,\lfloor C/2\rfloor),\qquad P_1=\min(P,P_{\max}),\\ (P_2,P_3)&=\operatorname{select}_{\xi}\mathcal C(P_1,C),\\ \mathcal C(P_1,C) &=\left\{\operatorname{round}(rP_1): r\in\{.5,.625,.75,.875,1.25,1.5,1.75,2,2.5,3\}\right\},\\ 4&\le P_r\le P_{\max},\qquad |P_r^{-1}-P_s^{-1}|\ge C^{-1}\quad(r\ne s),\\ A_{\mathrm{ms}}(k;b)&=\kappa_{b,\mathrm{ms}}\!\left(0.10+0.70\lambda_{b,\mathrm{ms}}(k)\right),\\ y_{t,j}&=a_{1j}\sin(2\pi t/P_1+\phi_{1j}) +A_{\mathrm{ms}}u_{2j}\sin(2\pi t/P_2+\phi_{2j})\\ &\quad+0.55A_{\mathrm{ms}}u_{3j}\sin(2\pi t/P_3+\phi_{3j}) +0.05m_q\cos(2\pi t/P_s+\psi_j) +b_j^{\mathrm{bg}}x_t+\epsilon_{t,j}, \end{aligned} \]

可预测状态切换 regime_switching

单目标显式驻留 motif主特征 regime_clock_history_incremental_r2
I↑：状态间距↑

\(\widehat\tau_t\)在 \(u_t\in[-1,1]\) 上对 \(\mathcal R(y)\) 拟合的二次趋势。\(\widehat\tau_t=\widehat\beta_2u_t^2+\widehat\beta_1u_t+\widehat\beta_0\)。
\(\widehat s_t\)对去趋势序列按 \(t\bmod P\) 分组求均值所得固定季节模板。不足两个周期时取 0。
\(e_t\)分解残差 \(\mathcal R(y_t)-\widehat\tau_t-\widehat s_t\)。本附录中与协变量能力的事件 \(e_t\) 无关。
\(y_t^\star\)结构统计使用的一维投影：\(y_t^\star=d^{-1}\sum_jY_{t,j}\)。level shift、谱、多周期、季节调制与非线性 gain 均在 \(\mathcal R(y^\star)\) 上计算；单目标时 \(y^\star=y\)。
\(\operatorname{Str}(a,b)\)\(\operatorname{clip}(1-\operatorname{Var}(a)/\operatorname{Var}(b),0,1)\)。趋势、季节 strength 的统一算子。
\(\rho_\ell(y)\)\(\operatorname{corr}(y_{1:T-\ell},y_{1+\ell:T})\)。零方差时返回 0。
\(R^2(y;D)\)以设计矩阵 \(D\) 做最小二乘后的决定系数。用于非线性 gain 与协变量 incremental \(R^2\)。
\(\Pi_P(y)\)长度为 \(P\) 的季节 phase profile。第 \(r\) 项为所有 \(t\bmod P=r\) 的均值，再整体去均值。
\(\mathcal F(y)\)去均值序列的实数 FFT 功率谱 \(|\operatorname{rFFT}(y)|^2\)。DC 分量置零。
\(\mathcal C\)允许的 change-point cuts。两侧长度均至少 \(\max(6,\min(24,\lfloor T/8\rfloor))\)。
\(\operatorname{corr}(a,b)\)Pearson correlation。向量长度不足 3 或零方差时返回 0。
